## แก้สตอรีบอร์ดจากหน้าเว็บ

1. เปิดหน้าเว็บจาก GitHub Pages (หรือไฟล์ `index.html` บนเครื่อง) → เปิดคลิป → ปุ่ม **✎ แก้ไข**
2. ใส่รหัสผ่านสำหรับแก้ไข (ขอจากผู้ดูแล) → แก้ ภาพ / Keyword บนจอ / เสียง เพิ่มหรือลบฉากได้
3. กด **บันทึกขึ้น Git** → หน้าเว็บ commit `src/rows9.json` และ `index.html` เข้า branch `main` ทันที (เวลาแต่ละฉากคำนวณใหม่อัตโนมัติ)

ตั้งหรือเปลี่ยนรหัสผ่าน (ผู้ดูแลเท่านั้น ทำบนเครื่อง ไม่มีบนหน้าเว็บ):
`pip install cryptography` แล้ว `python3 tools/set_editor_password.py` → ใส่ GitHub fine-grained token
(Repository access: เฉพาะ repo นี้ · Permissions: Contents = Read and write) และรหัสผ่านอย่างน้อย 12 ตัวอักษร
→ commit + push `src/editor-key.json` · token ถูกเข้ารหัสด้วยรหัสผ่าน (PBKDF2 + AES-GCM) ก่อนเก็บ

> `src/rows9.json` ใน repo คือข้อมูลล่าสุดเสมอ (รวมการแก้จากหน้าเว็บ) ก่อนแก้ไฟล์ใน `src/` บนเครื่อง ให้ `git pull` ก่อนทุกครั้ง

## เวอร์ชันละครซีรีส์ "ชั้น 12"

- ในหน้าต่างสตอรีบอร์ดมีปุ่มสลับ **เคสสั้น | ละครซีรีส์ "ชั้น 12"** ข้อมูลละครเก็บใน `src/rows9.json` ช่อง `drama` ของแต่ละคลิป (`title`, `cast`, `lead`, `est`, `sb`, `script`)
- แท็บ **Series ชั้น 12** (ก่อน Action Plan) รวมภาพรวมซีรีส์ เส้นเรื่องรายปี ฉากประจำ กติกาและมุกประจำ ตัวละครหลัก/หมุนเวียน คาแรกเตอร์ และตารางตัวเอก 71 ตอน (ตารางนี้สร้างจากช่อง `drama` ใน `rows9.json` ส่วนข้อความอื่นแก้ใน `src/body3.html`)
- ปุ่ม ✎ แก้ไข จะแก้เวอร์ชันที่กำลังแสดงอยู่ (เคสสั้นหรือละคร) แล้วบันทึกขึ้น Git
- ครบ 71 ตอนปรับบทให้อิงเคสจริง (เคสไทยก่อน ไม่มีจึงใช้ต่างประเทศ) ข้อมูลเคสและฉากที่ปรับอยู่ใน `src/drama/realcase.py` (ปีแรก) และ `src/drama/realcase2.py` (ปี 2–3 และเคสไทยที่สลับเข้าปีแรก รวมมุกท้ายตอน) และแสดงบนเว็บในช่อง "อ้างอิงเคสจริง" (ในคลิปไม่เอ่ยชื่อบริษัทจริง)
- ตัวละครเรียกตามหน้าที่ในตอนนั้น (พี่ HR, พี่จัดซื้อ, พี่เซลส์, หัวหน้าไซต์, น้องใหม่ ฯลฯ) ไม่ใช้ชื่อ ช่อง "ตัวละคร" ระบุ (ญ)/(ช) ไว้ให้ทีมคัดนักแสดง ในโค้ดยังใช้ชื่อเป็นตัวอ้างอิงภายใน แล้วแปลงเป็นป้ายหน้าที่ในขั้นสุดท้าย (`LABELS` ใน `gen.py`)
- `src/drama/gen.py` (ต้องมี pythainlp) สร้างช่อง `drama` ใหม่ทั้งหมดจากเวอร์ชันเคสสั้น ถ้าเคยแก้ละครผ่านหน้าเว็บแล้ว **ห้ามรันซ้ำ** เพราะจะเขียนทับสิ่งที่แก้ไว้
